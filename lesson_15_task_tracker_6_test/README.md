# Простой CRUD на FastAPI

Задачи хранятся в обычном списке Python. После перезапуска сервера все изменения
пропадут, и снова появятся две начальные задачи.

## Установка библиотек

Выполняйте команды по порядку, одну за другой.

1. Сначала установите FastAPI:

```bash
python3 -m pip install fastapi
```

2. Затем установите сервер Uvicorn:

```bash
python3 -m pip install "uvicorn[standard]"
```

Другие библиотеки отдельно устанавливать не нужно. Pydantic и остальные
зависимости установятся автоматически вместе с FastAPI и Uvicorn.

## Запуск backend

```bash
cd lesson_15_task_tracker_6_test
python3 -m uvicorn main:app --reload
```

Backend будет доступен по адресам:

- API: <http://127.0.0.1:8000/api/tasks>
- Swagger: <http://127.0.0.1:8000/docs>

## Запуск frontend

Откройте `index.html` через расширение Live Server в VS Code. Страница должна
открыться по адресу:

<http://127.0.0.1:5500>

Frontend и backend работают на разных портах. Поэтому в FastAPI настроен CORS,
который разрешает странице с порта `5500` отправлять запросы к порту `8000`.

## Запросы для Postman

| Метод | URL | Действие |
|---|---|---|
| GET | `http://127.0.0.1:8000/api/tasks` | получить все задачи |
| GET | `http://127.0.0.1:8000/api/tasks/1` | получить одну задачу |
| POST | `http://127.0.0.1:8000/api/tasks` | создать задачу |
| PUT | `http://127.0.0.1:8000/api/tasks/1` | изменить задачу |
| DELETE | `http://127.0.0.1:8000/api/tasks/1` | удалить задачу |

Тело POST-запроса:

```json
{
  "title": "Новая задача"
}
```

Тело PUT-запроса:

```json
{
  "title": "Новое название",
  "is_complete": true
}
```
